# Client website launch checklist

## Content and business details
- [ ] Confirm business name, legal details and contact information.
- [ ] Verify every product/menu item, price, currency, option and availability.
- [ ] Replace demonstration copy, photos, reviews and placeholder links.
- [ ] Confirm location, opening hours, delivery/pickup coverage and policies.
- [ ] Obtain permission for all client-supplied and third-party media.

## Functional checks
- [ ] Test every navigation link and CTA.
- [ ] Connect and test contact/reservation/order flows.
- [ ] Connect payment and checkout only through the agreed provider.
- [ ] Test cart behavior, stock rules, taxes, shipping and delivery fees if applicable.
- [ ] Test on current mobile and desktop browsers.

## Quality checks
- [ ] Run `npm run build` successfully.
- [ ] Check responsive layout at 360px, 390px, 768px, 1024px and 1440px widths.
- [ ] Check keyboard navigation, visible focus, labels and contrast.
- [ ] Add unique page title and meta description.
- [ ] Add favicon and social preview image.
- [ ] Optimize image dimensions, formats and loading behavior.
- [ ] Run Lighthouse and review Core Web Vitals on the deployed site.
- [ ] Check broken links, missing images, console errors and 404 pages.
- [ ] Configure domain, HTTPS, analytics and backups as agreed.
- [ ] Obtain client approval before launch.

## Handover
- [ ] Provide repository and deployment access.
- [ ] Explain how to edit content and prices.
- [ ] Document third-party services, recurring fees and account ownership.
- [ ] Clarify maintenance period, response times and what is out of scope.
